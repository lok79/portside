# Port Search · 端口搜索（工单 13）规格

澄清定稿于 2026-10-26（/grill-with-docs 两轮），术语见 [GLOSSARY.md](../../GLOSSARY.md)「端口搜索」。

## 需求

面板顶部常驻搜索框，输入端口号精确过滤服务行，解决「记得端口、反查服务」场景——浏览器开着 `localhost:8080`，想知道这是谁、看日志/停止它。

## 定稿决策（10 条）

1. **匹配维度**：只按端口号；不匹配名称/进程名。
2. **匹配方式**：精确匹配（整数相等），非子串。
3. **形态**：过滤列表——四区结构保留，分区计数随过滤实时变，无匹配分区整个隐藏；全部无匹配时全局空态「没有发现监听端口 N 的服务」。
4. **已停止托管定义行**按定义端口命中（空心点 +「已停止」如实区分，不猜）。
5. **聚合行**：任一子行端口命中 → 自动展开、只留命中子行；标题行保留原文（如「QQ（5 个端口）」）。
6. **入口**：列表顶部常驻（扫描提示行之下、四区之上），放大镜 + placeholder「搜端口号」+ 清空 ×。
7. **键盘**：Cmd+F 聚焦；聚焦时 Esc = 清空并退出聚焦（查询已空则仅退出聚焦）；未聚焦时 Esc 不接管，保持系统行为。
8. **持久性**：搜索词不持久，面板关闭/隐藏再开即清空。
9. **输入**：只放行数字（输入层过滤），粘贴清洗取数字；查询按整数比较（前导零无害）。
10. **「隐藏其他」**：搜索期间暂不生效（搜索优先），清空后开关恢复效力。

## 硬约束自查

- **低资源**：纯已发现数据上的渲染层过滤，不触发任何新扫描。
- **红线（外部服务降级形态）**：端口事实来自扫描器，托管/外部一视同仁可搜，本功能无降级分叉；搜索态下行内动作沿用现有行规格（外部行照旧灰停止/可收编）。
- **零遥测**：搜索词不出进程。
- 扫描不完整提示行照常显示，与空态共存；空态措辞限定「没有发现」，不承诺「不存在」（spec §1 诚实清单原则）。

## 关键假设与实测

- 无外部通道、无第三方集成、无未文档化数据源：功能封闭在既有 PanelRow / PanelViewModel / PanelView 接缝上（已通读），构建前无 empirical 探针需求。
- 两条实现性接线假设，留实现期实测（失败即回本规格调整）：
  1. Cmd+F 经隐藏 Button + `.keyboardShortcut` 注册到窗口生效；
  2. 聚焦态 Esc 经 `.onExitCommand` 接管且不影响系统关窗行为。
  实测结果回填工单 Comments。

## 验收标准

1. 输 `8080` → 只剩端口为 8080 的行；已停止定义行同样命中。
2. 输 `80` → 零命中（精确匹配），全局空态出现。
3. 输字母 → 进不了输入框；粘贴 `:8080` 清洗为 `8080`。
4. QQ 聚合行含端口 61234 且「隐藏其他」开着，输 `61234` → 聚合行自动展开、只留该子行，「隐藏其他」清空搜索后恢复效力。
5. Cmd+F 聚焦搜索框；聚焦时 Esc 清空并退出；面板关闭重开搜索为空。
6. `swift test` 全绿；实机冒烟：起一个本地服务 → 按端口搜到 → 行内日志/停止按钮照常可用。
