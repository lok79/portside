# 05: 服务定义持久化与收编

**What to build:** 点外部服务行的「收编」，弹三字段预填表单（名称=清洗识别名、启动命令=该进程当前 argv 原样、端口=当前端口），可改可取消；保存后生成服务定义，服务移入「我的服务」并升级托管标签。定义持久化到应用容器（JSON），重启 app 后仍在（含已停止态与「启动」按钮）。别名可编辑；定义含浏览器打开的路径前缀字段（默认空）。
