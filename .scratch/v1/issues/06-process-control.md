# 06: 进程管理——启动/停止/重启与进程组

**What to build:** 「我的服务」里能启动/停止/重启：启动经用户登录 shell（继承 nvm 等环境，LocalPorts 教训）、输出直写落盘日志文件、独立进程组；停止对整组先 SIGTERM 超时再 SIGKILL；停止/重启前有二次确认（显示服务名与解释）；失败启动错误可见不崩 app。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 启动 shell 命令服务：进程进独立组，落盘日志文件出现且持续写入（脚本循环输出验证）
- [ ] 启动环境继承登录 shell：测试脚本里 `echo $PATH`/nvm 场景可用
- [ ] 停止：SIGTERM → 超时 → SIGKILL 整组；用 fork 子进程的测试脚本验证无孤儿残留（ps 对照）
- [ ] 重启 = 停止 + 启动，UI 状态按 已运行→已停止→运行中 迁移
- [ ] 停止/重启前确认弹窗：显示服务名/端口与动作解释
- [ ] 启动失败（命令不存在/立即退出）：错误信息在行内可见，app 不崩
